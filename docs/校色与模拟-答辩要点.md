# 校色与模拟 · 答辩要点（校色模式的价值证明）

> 2026-09-22 定稿 · 配套《PPT大纲.md》第 4 / 9 页与《演示视频分镜.md》镜 3 / 镜 5。
> 文中所有数字均可用文末脚本复现；矩阵与 `app/frontend/theme_cvd.js` 的 `M_FULL.deutan` 严格同源（Machado 2009 @ severity=1，线性 RGB）。

---

## 一、一句话定位（可直接上 PPT）

- **校色 correct**：不是"让色盲看见绿色"，而是**把红绿轴上承载的信息，放大回色弱用户的分辨阈之上**（实测可分辨性 46% → 64%）。
- **模拟 simulate**：不是给色盲用户的功能，而是**给正常视力的设计者/评委的透视镜**——看见问题 + 验证校色效果。

## 二、受众区分（评委最容易混淆的一点）

| | 校色 correct | 模拟 simulate |
|---|---|---|
| 给谁用 | 屏幕前的**色觉异常用户** | **正常视力**的你 / 评委 / 设计者 |
| 回答的问题 | "色弱用户分不分得清" | "色弱用户看到的是什么" |
| 数学 | (1+s)·I − s·M（残差补偿，反向预加重） | (1−s)·I + s·M（正向投影） |
| 类比 | 助听器：把语音放大进残存听阈 | 体验耳机：让别人听见你听见的世界 |

两个功能的服务对象**互斥**。"校色完再模拟给色盲用户看"是把工具用错了对象。正确演示顺序（四步）：

1. 原色页面；
2. 加 `?cvdsim=deutan&cvdsev=0.6` → 评委**看见问题**（哪些色对坍缩）；
3. 关模拟、开校色 → 这是给用户的真实使用态；
4. 两个窗口并排对比「模拟(未校色)」vs「模拟(校色后)」→ 评委**亲眼看到坍缩的色对重新拉开**——模拟管线就是校色的验收仪器。

## 三、数值验证（deutan · severity 0.6 · 线性 RGB 域欧氏差）

| 色对 | 正常眼 Δ | deutan 未校色 | deutan 校色后 |
|---|---|---|---|
| 莓果玫红 #A63D57 vs 裸红 #B66C71 | 0.152 | 0.156（103%） | 0.154（101%） |
| 莓果玫红 #A63D57 vs 灰粉 #C9808C | 0.312 | 0.308（98%） | 0.309（99%） |
| **眼影绿 #6B8E5A vs 红棕 #8E6B5A** | 0.175 | **0.080（46%）** | **0.112（64%）** |
| **正红 #9B2C3F vs 橄榄绿 #5F7A4F** | 0.274 | **0.117（43%）** | **0.175（64%）** |
| 纯红 #C0392B vs 纯绿 #27AE60 | 0.642 | 0.280（44%） | 0.414（65%） |
| 混淆轴方向增益（单位差） | 1.000 | 0.400 | 0.640（恰 1.60×） |

两个关键读数（也是反直觉的洞察，答辩可主动讲）：

1. **红系色号内部并不坍缩**（103% / 98%）——玫红和豆沙红的差异主要在明度/蓝黄轴上，色弱用户分得清。"红色口红全一样"是误解；
2. **真正坍缩的是红绿相对的色对**（46% / 43% / 44%），而校色恰好只对这类色对生效（→ 64%，精确的 1+s = 1.6 倍）——补在刀刃上，且不破坏其余颜色观感。

## 四、数学小抄（评委追问时的防线）

- deutan 混淆轴：M·d ≈ 0 的方向，实测 d ≈ (0.92, −0.39, 0.03)（线性 RGB 的 L 锥轴）；
- 沿该轴增益：未校色 (1−s) = 0.40；校色后 simulate∘correct = (1−s²) = 0.64；**比值恒为 1+s**；
- 等效表述：severity 0.6 的用户开了校色 ≈ 严重度降到 s² ≈ 0.36（沿混淆轴）；
- **诚实边界**：s = 1.0（完全二色视）时两者皆 ≈ 0——校色对完全二色视数学上无效（残差被加回其失明的轴，属感知恒等变换）。这不是实现 bug，是此类技术的固有边界，学界对 Daltonization 对 dichromat 的实效本有争议。

## 五、对完全二色视的兜底（主动讲 = 展示思考深度）

1. **信息冗余**：每个色号都带文字名 + hex（试妆部位卡已实现）——二色视唯一可靠的通道；
2. **重配色 / 明度分离**：把靠红绿承载的差异搬到明度轴上（改设计，而非校色）；
3. **AI 语义推荐**：def 43 按五官档案直接推荐，本身绕开纯色觉问题。

## 六、标准答辩口径（照念版）

> "校色不是恢复色彩感知——那需要治视网膜。我们做的是把设计里靠红绿差异承载的信息，放大回色弱用户还能感知的维度上：沿 Machado 混淆轴放大 1.6 倍，实测典型红绿色对的可分辨性从 46% 恢复到 64%，蓝黄轴与明度不受影响。对完全二色视我们诚实标注边界——矩阵校色对他们无效，我们用每个色号的文字标签和 AI 语义推荐兜底。模拟模式则是这套效果的验证仪：校色前后，评委能亲眼看到坍缩的色对重新拉开。"

## 附：数值复现脚本

```python
import numpy as np

M = np.array([[0.367322, 0.860646, -0.227968],
              [0.280085, 0.672501,  0.047413],
              [-0.011820, 0.042940, 0.968881]])   # = theme_cvd.js M_FULL.deutan（Machado 2009 @ s=1，线性 RGB）
I = np.eye(3); s = 0.6
sim  = (1 - s) * I + s * M     # 模拟：M_sev
corr = (1 + s) * I - s * M     # 校色：2I − M_sev 的展开

w, v = np.linalg.eig(M)
d = np.real(v[:, np.argmin(np.abs(w))]); d /= np.linalg.norm(d)   # deutan 混淆轴
print("axis gain  no-corr %.3f | with-corr %.3f | ratio %.2f"
      % (np.linalg.norm(sim @ d), np.linalg.norm(sim @ corr @ d),
         np.linalg.norm(sim @ corr @ d) / np.linalg.norm(sim @ d)))
# → 0.400 | 0.640 | 1.60

def L(h):
    c = np.array([int(h[i:i + 2], 16) for i in (0, 2, 4)], float) / 255
    return np.where(c <= 0.04045, c / 12.92, ((c + 0.055) / 1.055) ** 2.4)

for a, b, name in [("6B8E5A", "8E6B5A", "green vs red-brown eyeshadow"),
                   ("9B2C3F", "5F7A4F", "red vs olive green"),
                   ("C0392B", "27AE60", "pure red vs pure green")]:
    dd = L(a) - L(b); n = np.linalg.norm(dd)
    print("%-32s lin %.3f | deutan %.3f (%3.0f%%) | deutan+corr %.3f (%3.0f%%)"
          % (name, n, np.linalg.norm(sim @ dd), 100 * np.linalg.norm(sim @ dd) / n,
             np.linalg.norm(sim @ corr @ dd), 100 * np.linalg.norm(sim @ corr @ dd) / n))
```
