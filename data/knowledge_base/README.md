# knowledge_base

该目录是 ColorBoundless 的色彩知识库总入口，负责保存：

- 基础色卡（基础 palette）
- 风格色卡（style palette）
- 配色规则（color rules）
- 色盲与可访问性规则（CVD rules）

它不等于普通数据样本，而是用于支撑 LLM / Agent / RAG 的“美妆配色事实层”。

建议在该目录中持续扩展：

- base_palette/: 主色、辅色、冷暖基础色卡
- style_palette/: 高级感、甜美、复古、编辑风等风格调色板
- color_rules/: 配色理论逻辑与筛选规则
- cvd_rules/: 色盲友好与灰阶可读性规则
