# color_test_questions

该目录用于存放“色盲/可访问性测试题库”，不是通用图像数据目录。

职责：

- 保存色盲测试题图
- 保存题目描述与正确答案
- 保存测试规则（例如选择题、二值判断、对比判断）
- 记录答案解析与目标人群适配说明

适用场景：

- 模拟不同类型色盲
- 验证配色在低对比与色觉偏差场景下的可辨识性
- 评估整体视觉体验是否仍然可理解

建议文件命名：

- q01_red_green_vision.json
- q02_blue_yellow_vision.json
- q03_grayscale_check.json
- q04_full_color_blind.json
