# rag 模块

RAG（Retrieval-Augmented Generation）负责为模型提供可追溯的美妆知识背景，避免直接凭经验生成不可靠推荐。

核心用途：

- 检索品牌色号数据
- 检索配色建议与色彩规律
- 检索肤色适配规则
- 检索场景与风格知识
- 结合美妆经验与用户输入生成解释性建议

典型数据来源：

- 品牌色号库
- 色卡数据
- 美妆搭配文档
- 风格文档
- 评估规则与可访问性说明

推荐设计：

- query: 用户需求
- context: 相似色卡、搭配文档、肤色适配说明
- response: 用事实支撑的推荐与解释

说明：

RAG 是避免 LLM 幻觉的关键组件，不应该只依赖模型本身生成颜色建议。
