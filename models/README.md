# models 模块

该目录用于放置“模型资源”与“知识增强层”，包括：

- face_parsing: 人脸分割与遮罩模型
- rag: RAG 检索增强层
- vector_store: 向量数据库 / embedding 索引

职责说明：

- 视觉模型负责识别和分割
- RAG 负责接入美妆知识库、配色知识和审美说明
- 向量库负责索引调色板、时尚风格、产品知识和使用说明

## 训练分工

### 1. 色彩基础模型

- 训练对象：RGB / HEX / Lab 聚类、近似色检索、色相族识别
- 目标：让模型能够在颜色空间中找到相近色与匹配色
- 适合结构：embedding + KNN / FAISS

### 2. 肤色适配模型

- 训练对象：肤色分类、undertone 分析、化妆品色号匹配
- 目标：给出适合某一肤色的底妆与唇色区间
- 适合结构：回归 / 分类 / ranking

### 3. 风格推荐模型

- 训练对象：风格标签、场景、搭配关系
- 目标：在不同用户表达下生成“冷感 / 暖感 / 复古 / 日常 / 编辑风”推荐
- 适合结构：ranking model + RAG 解释

### 4. CVD 安全过滤器

- 训练对象：对比度、失色模拟、可辨识性评分
- 目标：避免推荐低可读、低识别的搭配
- 适合结构：规则引擎 + 模型辅助评分

### 5. 视觉妆容模型

- 训练对象：脸部妆容区域、颜色映射、妆容风格识别
- 目标：把图像中的妆容风格映射到配色库
- 适合结构：分割 + 分类 + embedding

最终目标：

- 图像识别是基础
- 色彩推荐是规则
- LLM 负责语言生成
- RAG 负责把“事实”和“数据库”绑定起来，避免幻觉
